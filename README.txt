VIRCOON — SITIO HTML, CSS Y JAVASCRIPT

1. Abre index.html para visualizar la página principal.
2. Edita css/styles.css para cambiar colores, tamaños y distribución.
3. Edita js/script.js para modificar el menú y el formulario.
4. Las imágenes están en /images y los videos en /videos.
5. Puedes subir la carpeta completa a un hosting tradicional conservando su estructura.

Páginas:
- index.html
- servicios.html
- proyectos.html
- contacto.html

El formulario abre el programa de correo del visitante y prepara un mensaje para contacto@vircoon.com.
